# 「加害者是誰・這樣的對待合理嗎」審稿清單

共 69 位。每筆:加害者 / 為什麼不合理(只寫有出處的事實) / 後來。「後來」留空代表沒有查到可靠出處,結果頁就不寫,不會編造。

審稿重點:①加害者的稱呼是否精準 ②有沒有寫了你覺得出處不足的話 ③吳石、簡吉等本人曾參與中共活動者,是否仍要放進來(我保留,但只寫事實) ④呂赫若不收錄的理由。
