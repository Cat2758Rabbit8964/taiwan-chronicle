# 台灣事件簿

按時間軸呈現台灣各時代的事件與生活樣貌,並在東亞地圖上同步顯示台灣、中國、日本與世界的同期事件。

靜態網站(HTML / CSS / JavaScript),不需要建置步驟。本機預覽:

    python3 -m http.server 8765

開啟 http://localhost:8765/ 。

## 資料與出處

- 事件內容整理自維基百科、國史館與各媒體報導,每個事件的參考資料列在事件的「完整背景與參考資料」。內容完整度與待補項目見頁面標示;`python3 scripts/check.py` 可檢查資料格式。
- 事件中的刑事案件(如跨境鎮壓、罷免連署偽造)多為起訴階段,被告適用無罪推定,以判決為準。
- 相片來自 Wikimedia Commons,以連結方式顯示,不在此儲存。每張相片的說明下方標示授權,點圖可到 Commons 頁面查看原作者與授權條款。
- 地圖:MapLibre GL JS(BSD-3-Clause),底圖 © OpenStreetMap contributors。

## 互動遊戲

`game.html` 是「尋找你上輩子的樣子」:輸入生日,回到過去的一個時間,回答一個志向題與至少三個情境題(以故事講述),配對到一位已過世的歷史人物。你的每個選擇,都對應到該人物在歷史上真正做過的事。資料在 `data/game.json`,共 183 位台灣(126)、日本(32)與中國(25)的人物,規則是人物的逝世日不得晚於使用者的生日。

- 人物資料整理自維基百科中文條目、國家人權記憶庫與一篇學術論文(詳見每位人物的出處連結),大多只有單一來源,未交叉核對。
- 人物的「出生地類型」(港口、大城市、農村小鎮、山林邊地)是本遊戲自行的分類,不是史實,只用來配對加分。
- 每位人物的 `acts` 欄位記錄他在五種情境(面對當局、逆境、機運與認可、局勢劇變、最後一章)下實際做的事與出處事實;選擇會依這些紀錄篩選人物,所以結果一定能對回你實際走上的每一步。選項符合的人太少時,故事會「轉折」到另一個選項。志向只影響加分,不篩人物。條目沒寫的事不列。
- 生日只在瀏覽器內計算,不會上傳或儲存。

- `scripts/game/sim.py` 以隨機玩家模擬數十萬局,檢查每位人物的出場機會,並可用 `--balance` 調整各人物的平衡權重(`wt`);`scripts/game/harness.js` 用假 DOM 在 macOS 的 `osascript -l JavaScript` 裡跑一局。權重只影響「同樣符合你選擇的人」誰先出場,不會挑出和你選擇對不上的人。
