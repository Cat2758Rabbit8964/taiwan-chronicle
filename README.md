# 台灣事件簿

按時間軸呈現台灣各時代的事件與生活樣貌,並在東亞地圖上同步顯示台灣、中國、日本與世界的同期事件。

靜態網站(HTML / CSS / JavaScript),不需要建置步驟。本機預覽:

    python3 -m http.server 8765

開啟 http://localhost:8765/ 。

## 資料與出處

- 事件內容整理自維基百科、國史館與各媒體報導,每個事件的參考資料列在事件的「完整背景與參考資料」。內容完整度與待補項目見頁面標示;`python3 scripts/check.py` 可檢查資料格式。
- 事件中的刑事案件(如跨境鎮壓、罷免連署偽造)多為起訴階段,被告適用無罪推定,以判決為準。
- 相片來自 Wikimedia Commons,以連結方式顯示,不在此儲存。每張相片的說明下方標示授權,點圖可到 Commons 頁面查看原作者與授權條款。
- 地圖:MapLibre GL JS(BSD-3-Clause),底圖 © OpenStreetMap contributors。
